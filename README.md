# 📅 Smart Planner (Умный планировщик)

**Smart Planner** — это десктопное приложение для удобного планирования семейного расписания и контроля регулярных бытовых дел. Проект написан на Python с использованием современного графического фреймворка PyQt6.

## ✨ Основные возможности

*   👥 **Мультипользовательский режим:** Добавляйте членов семьи или команды, назначайте им уникальные цвета. События автоматически окрашиваются в цвет владельца.
*   🔄 **Умные повторяющиеся события:** Планируйте встречи, репетиции или уроки на недели вперед. 
*   ⏸️ **Гибкое удаление (Пропуск дней):** Если репетитор отменился на время каникул, вам не нужно удалять всё событие. Программа скроет только один конкретный день, сохранив остальные.
*   ⏱️ **Ежемесячные дела:** Учет редких задач (замена фильтров, поверка счетчиков). Приложение само рассчитает, когда наступит следующий раз, и подсветит красным, если время подходит.
*   🎨 **Современный UI/UX:** Поддержка светлой и темной темы. Кастомные карточки событий и плавные анимации интерфейса.
*   💾 **Локальная база данных:** Все данные надежно хранятся в SQLite (файл `planner.sqlite`) и не пропадают после закрытия программы.
